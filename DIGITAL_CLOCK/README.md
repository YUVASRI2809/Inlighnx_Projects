# ⏰ Digital Clock

## Project Description
Digital Clock is a simple web application that displays the current time in real-time. It updates every second and provides a clean, responsive user interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Displays current hours, minutes, and seconds.
- Updates automatically every second.
- Responsive design.
- Simple and user-friendly interface.

## Project Structure
DIGITAL_CLOCK/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.

- JavaScript Date object
- setInterval()
