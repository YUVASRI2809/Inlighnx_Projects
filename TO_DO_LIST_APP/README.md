# ✅ To-Do List Application

## Project Description
To-Do List Application helps users organize their daily tasks efficiently by allowing them to add, complete, and delete tasks.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Input validation.
- Local Storage persistence.

## Project Structure
TO_DO_LIST_APP/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.

## Learning Outcomes
- DOM manipulation
- Event listeners
- Local Storage
- Dynamic UI updates
