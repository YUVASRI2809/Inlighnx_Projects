# 📝 Interactive Quiz Application

## Project Description
Interactive Quiz Application enables users to answer multiple-choice questions and receive a score at the end of the quiz.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Multiple-choice questions.
- Score calculation.
- Results summary.
- Restart quiz functionality.
- Responsive design.

## Project Structure
QUIZ_APP/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.

## Learning Outcomes
- Arrays and objects
- Conditional statements
- Event handling
- DOM manipulation
